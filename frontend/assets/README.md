# Recursos visuales

- `stay-hero.png`: imagen de una estancia ficticia generada con ImageGen para
  Opinómetro. No representa un alojamiento real ni una reseña del dataset.
  Usada únicamente como fondo decorativo en la portada, con capas CSS para
  contraste y transición al fondo oscuro del resto de la aplicación.
- `stay-key.svg`: ilustración vectorial decorativa de una llave.
- `stay-door.svg`: ilustración original de una puerta entreabierta con luz,
  planta, maleta y conversación de huésped para la sección de cierre.
- `favicon.svg`: icono vectorial original del proyecto.

Las burbujas, órbitas, tarjeta de bienvenida y animaciones se construyen con
HTML/CSS. Los recursos se incluyen localmente, sin depender de imágenes remotas.
