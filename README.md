# 📊 Proyecto Integrador: Aplicación Web de NLP para Clasificación de Sentimiento
Materia: Tópicos y Programación Avanzada

## 🚀 Arquitectura del Proyecto
El proyecto sigue una metodología en cascada con la siguiente estructura oficial:
- `data/`: Datos crudos de reseñas.
- `notebooks/`: Análisis exploratorio de datos (EDA).
- `src/nlp/`: Pipeline de preprocesamiento lingüístico.
- `src/models/`: Entrenamiento y evaluación de Inteligencia Artificial.
- `api/`: Backend estructurado en FastAPI.
- `frontend/`: Interfaz web interactiva (Opinómetro).
