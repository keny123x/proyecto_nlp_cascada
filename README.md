## 🛠️ Instalación y Ejecución Base

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com
   cd proyecto_nlp_cascada
   ```

2. **Instalar las dependencias del proyecto:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Validar el Preprocesamiento de Datos (Fase 1):**
   ```bash
   python src/nlp/preprocess.py
   ```
